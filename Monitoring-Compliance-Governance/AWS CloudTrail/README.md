# AWS CloudTrail

## Overview

As part of my AWS Cloud learning journey, I explored **AWS CloudTrail**, a service that records activities performed in an AWS account. CloudTrail helps organizations monitor user actions, improve security, investigate issues, and maintain audit records.

## Why Auditing is Important

Auditing helps organizations keep track of everything happening in their AWS environment. It provides a history of activities, making it easier to:

* Improve security
* Investigate unexpected changes
* Troubleshoot problems
* Meet compliance requirements
* Understand who performed an action and when it happened

## Benefits and Use Cases of AWS CloudTrail

AWS CloudTrail records **API calls** made in your AWS account. This allows organizations to:

* Monitor user and account activity
* Detect unauthorized or suspicious actions
* Investigate security incidents
* Maintain audit records for compliance
* Track changes made to AWS resources

## CloudTrail Events

CloudTrail Events are the individual actions that occur in your AWS account. Examples include:

* Launching an EC2 instance
* Creating an S3 bucket
* Updating an IAM policy
* Deleting an AWS resource

Each event contains details about the action that was performed.

## CloudTrail Logs

CloudTrail stores events as **logs**, which include information such as:

* Who performed the action
* When the action occurred
* Which AWS service was used
* The API call that was made
* The source IP address

These logs help with troubleshooting, auditing, and security investigations.

## CloudTrail Insights

CloudTrail Insights uses machine learning to identify unusual API activity in your AWS account. It can detect unexpected increases in API calls or unusual operational patterns, helping organizations identify potential security or operational issues more quickly.

## Key Learning

Learning AWS CloudTrail has helped me understand that cloud engineering is not only about creating cloud resources. It is also about keeping a detailed history of activities, monitoring changes, improving security, and responding quickly to unexpected events.

CloudTrail is an essential AWS service for auditing, compliance, governance, and cloud security.
