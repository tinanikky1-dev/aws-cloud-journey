# Amazon CloudWatch

## Overview

As part of my AWS Cloud learning journey, I explored **Amazon CloudWatch**, an AWS monitoring and observability service that helps track the performance, health, and activities of cloud resources and applications.

Monitoring is an important part of cloud engineering because it helps identify issues early, improve system performance, and maintain reliable applications.

## What is Amazon CloudWatch?

**Amazon CloudWatch** collects monitoring data from AWS resources, applications, and services. It helps cloud engineers view metrics, analyze logs, create alerts, and respond to operational issues.

## Key Features of Amazon CloudWatch

### 1. Metrics Monitoring

CloudWatch collects performance data from AWS resources, such as:

* CPU utilization
* Network activity
* Disk usage
* Application performance

These metrics help engineers understand the health and performance of their systems.

### 2. Log Monitoring

CloudWatch Logs collects and stores logs from applications, servers, and AWS services. This makes it easier to troubleshoot errors and investigate system activities.

### 3. CloudWatch Alarms

CloudWatch Alarms allow users to set conditions and receive notifications when a specific threshold is reached.

Example:

* Sending an alert when EC2 CPU usage becomes too high.

### 4. Dashboards

CloudWatch Dashboards provide a visual view of important metrics and resources in one place, making monitoring easier.

### 5. Automated Actions

CloudWatch can trigger automated responses when events occur. It can work with other AWS services to help improve system reliability.
